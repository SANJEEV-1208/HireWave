============================================================
Job Portal — Backend System Requirements
============================================================

REQUIRED SOFTWARE
-----------------
Java JDK 21+        https://adoptium.net
Apache Maven 3.8+   https://maven.apache.org/download.cgi
PostgreSQL 14+      https://www.postgresql.org/download/

SETUP STEPS
-----------
1. Install the software above.

2. Create a PostgreSQL database:
      CREATE DATABASE jobportal;

3. Set environment variables (IntelliJ: Run > Edit Configurations > Environment Variables):
      DB_URL=jdbc:postgresql://localhost:5432/jobportal
      DB_USERNAME=postgres
      DB_PASSWORD=your-db-password
      JWT_SECRET=any-64-character-random-hex-string
      MAIL_USERNAME=your-email@gmail.com
      MAIL_PASSWORD=your-gmail-app-password
      GOOGLE_CLIENT_ID=your-google-oauth-client-id
      GROQ_API_KEY=your-groq-api-key
      CORS_ALLOWED_ORIGINS=http://localhost:5173

4. Run the application:
      mvn spring-boot:run
   Or open in IntelliJ IDEA and run DemoApplication.java.

5. Backend starts at http://localhost:8081

JAVA DEPENDENCIES (managed automatically by Maven via pom.xml)
--------------------------------------------------------------
Spring Boot 4.0.5
Spring Data JPA + Hibernate
Spring Security
Spring WebSocket (STOMP)
Spring Mail
PostgreSQL JDBC Driver
JJWT 0.12.5              (JWT authentication)
Lombok
Apache PDFBox 3.0.3      (resume text extraction)
Bucket4j 8.10.1          (rate limiting)
Google API Client 2.2.0  (Google OAuth)
Jackson Databind          (JSON)

NOTE: Maven downloads all Java dependencies automatically on first build.
No manual jar installation is needed.
